# Hi, I'm WonJun 👋

I'm a backend developer who loves **designing architectures that solve real problems under real constraints** — cost, scale, policy, domain rules — and finding the most elegant solution within those boundaries.

I don't just write code. I enjoy the **full loop**: understanding user needs, designing systems, shipping to production, monitoring, and iterating. I've run a live service with 200+ users for 5 months, and that end-to-end experience is what drives me.

### What I Care About

🏗️ &nbsp; Architecture over implementation — I think in systems, patterns, and trade-offs before touching code

🤝 &nbsp; Balance of depth & communication — I love deep technical dives, but I'm equally energized by team discussions, code reviews, and customer-facing work

📡 &nbsp; Staying current — I regularly watch tech conference talks (Kakao, AWS re:Invent, etc.) and experiment with new approaches when they prove practical

🚀 &nbsp; Shipping things that matter — one-off hackathon projects are fine, but I'm most proud of services that real people actually use
